# MediaCore — собственный видеохостинг для VRChat

**MediaCore** позволяет загружать, конвертировать и стримить видео прямо в миры VRChat.
Поддерживает популярные видеоплееры (USharpVideo, ProTV, YamaPlayer, IwaSync3, VizVid),
генерирует правильные ссылки и плейлисты, а также умеет отправлять ссылки в чат VRChat
по OSC.

![MediaCore Screenshot](screenshot.png)

## Возможности

- **Загрузка видео** — через веб-интерфейс (файлом) или по ссылке YouTube.
- **Автоматическая конвертация** в MP4 (H.264/AAC) с прогресс-баром.
- **Превью** — автоматический скриншот на 2-й секунде.
- **Выбор плеера** — USharpVideo, ProTV/YamaPlayer, IwaSync3, VizVid. Для каждого генерируется корректная ссылка или JSON-плейлист.
- **Отправка в VRChat** — одним кликом через локальный OSC-прокси.
- **Админ-панель** — статистика, логи просмотров, управление плейлистами, настройки.
- **Логирование** — запись всех операций (загрузка, конвертация, действия админа) в файлы логов.
- **Сохранение сессии** — админ остаётся авторизованным даже после перезапуска сервера.
- **Мобильная адаптация** — удобный просмотр на телефонах и планшетах.
- **Лёгкая установка** — один bash-скрипт для Ubuntu.

## Установка

Требования: Ubuntu Server 22.04/24.04, root-доступ, домен с SSL-сертификатами (`.crt` и `.key` в `/usr`).

1. Скопируйте установочный скрипт `install.sh` на сервер.
2. Сделайте исполняемым: `chmod +x install.sh`
3. Запустите от root: `sudo ./install.sh`
4. Следуйте инструкциям (выберите режим установки, задайте пароль админа).
5. После завершения сайт будет доступен по вашему домену (например `https://*Ваш домен*`).

В процессе установки:
- создаются папки `/opt/mediacore` (приложение) и `/opt/video` (видеофайлы);
- настраивается Nginx;
- запускается systemd-сервис `mediacore`.

## Использование

### Гостевая часть (без авторизации)
- Просмотр библиотеки видео с поиском.
- Копирование прямой ссылки или отправка в VRChat (требуется запущенный OSC-прокси).
- Недавно просмотренные сохраняются локально в браузере.

### Администратор (логин: `admin`, пароль задаётся при установке)
- Загрузка видео (файл или YouTube).
- Просмотр статистики и логов просмотров.
- Управление плейлистами.
- Настройка сайта (количество колонок, заголовок, HLS).

### OSC-прокси
Для работы кнопки «Отправить в VRChat» необходимо запустить `osc_bridge.py` на компьютере с VRChat:
1. Скачайте скрипт с сайта (`/get/osc_bridge.py`).
2. Установите зависимости: `pip install flask python-osc`
3. Запустите: `python osc_bridge.py`
4. Прокси слушает `localhost:9999`. Теперь кнопка «Отправить в VRChat» работает.

## Логирование

MediaCore подробно логирует все важные события:
- `logs/process.log` — запуск и прогресс конвертации, скачивания YouTube.
- `logs/admin.log` — действия админа (вход, загрузка, удаление, изменение настроек).
- `logs/error.log` — ошибки во время конвертации или загрузки (создаётся автоматически при ошибках).

Логи можно просматривать прямо в админ-панели (только логи просмотров видео).

## Технологии

- Nginx (прокси и отдача статики)
